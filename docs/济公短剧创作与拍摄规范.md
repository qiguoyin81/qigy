## 1. 已确定的创作方向

以济公为核心，做有生活代入感的市井奇幻讽刺喜剧。参考周星驰作品中小人物处境、喜剧与奇幻相互推动的方法，创作原创人物关系和情节。用以下三问检查每场关键戏：委屈能不能被看见？笑点能不能被看懂？受助者最后有没有真正得到帮助？

济公有神性、有法术，也有体恤人的温度。遇见困难会介入；可以先观察以弄清缘由，但不能为延长剧情而故意让人继续受苦。对受助者尊重，对占便宜、欺负人的人可以戏谑。法术必须参与因果、揭示事实或解决实际困难，不能成为与剧情无关的特效表演。每集不规定法术次数。

古代和现代都可以，不预先限制时代。以具体故事决定情绪铺垫与事件推进的比重，不用性别刻板印象替代人物塑造。优先商业目标是尽快获得收入，兼顾带货和广告的可能性；具体变现形式尚未细分，不预设每集必须植入商品。

## 2. 竞品参考及证据边界

参考：古叔《济新传：乐于助人的你，往往会委屈了自己》。链接：https://www.douyin.com/video/7706388249694063899 。页面视频时长约3分53秒。

已通过浏览器分段核对关键画面和烧录字幕，未完成逐帧、完整音轨和剪辑节奏审听。以下观察不等于全面制作鉴定，也不据此推断播放量、完播率、收益或成功原因。

可见手法：

- 古代村落、土墙、木门、磨旧的衣服和劳动道具，组成朴素、偏土色的生活环境；画面呈写实AI影像质感，人物皮肤、衣料、建筑表面有纹理。
- 可见横向宽画幅；多人劳动和院落场景交代人物与环境，中景、近景承担对话和神情展示。
- 门口求助的场景利用门框和门缝，把双方的位置及张三在门外的处境呈现出来。
- 济公和小和尚在部分画面中与张三同处场景，通过观察和对话解释张三的处境。
- 画面同时使用对白字幕与解释事件的橙色文字。不能把播放器弹幕误当成作者制作的字幕。
- 付出与求助形成前后对照：张三拿工钱换米帮邻居、帮人干活；自己遇到急事后开口借钱；之后出现拒绝继续帮忙的转变。

这些片段更偏人情寓言。我们吸收其生活质感与情绪对照，增加济公的行动、法术对冲突的作用和清楚的喜剧结果。

## 3. 竞品拍摄评价与提升方向

基于已核对片段，主观给7/10。范围限定为可见构图、场景、人物呈现与视听叙事中的视觉部分，不是对全片摄影、声音、剪辑的完整评分。其长处是场景统一、人物处境易懂、前后关系容易形成共鸣。

主要提升方向：

1. 把部分说明改成可见动作。解释他用工钱帮人时，可以先拍他数钱、留下自己的饭钱，犹豫后再把那一点也拿出。只选与本集因果有关的动作，不为煽情堆砌贫苦细节。
2. 增强同一关系的前后镜头呼应。别人来找他时，他让开门、放下碗；他去求助时，对方挡着门、迟迟不接话。保留相似机位或道具，让观众自己看出态度变化。这是我们的改进方案，不是声称竞品已拍过全部动作。
3. 让关键情绪有反应镜头。求助遭到推辞后，可让当事人先把要说的话咽回去，收回递出的手，再离开。不要每次都落泪，不把所有台词演成控诉。
4. 让济公的解释更精炼。让关键判断在行动中成立；已被情节表达的道理，不再用字幕、对白、旁白重复三遍。
5. 增加真正改变处境的结尾。我们的济公要落实帮助：钱拿回来、误会解开、生活难题得到处理。受助者也要有自己的选择。只解释委屈、不解决困境，不能作为本系列的常规结尾。

实际光线参数、焦段、镜头运动速度、配音音色、配乐音量和逐秒剪辑点，当前证据不足，不以竞品名义固定。

## 4. 故事线规则

先根据目标受众提出几个话题，选定话题后再确定一个故事，故事确定后再写剧本。故事线需交代片名、开头的疑问、人物所求、冲突因果、情绪变化、济公怎样介入、反转依据、实际结局和师徒收尾。不要在故事未定时一次铺开多个版本和大量制作参数。

片名要让观众知道故事在讲什么。优先使用人物、具体事情与主要矛盾；可以留解决方式的悬念，但不空写“人性”“善恶”“一念”。标题承诺必须在剧情中兑现，不要求每集都用完全相同的标题句式。

贪、嗔、痴是创作主题，进入故事时应化成具体的人情困境，例如“一直体谅别人，结果自己的退让被当成理所当然”。一集抓住一个主要矛盾。

写明主角为什么忍、为什么现在必须处理、自己已经做过什么。退让应有现实代价与动机，比如搬家车在等、怕影响生计、珍惜关系；不能靠主角突然失去判断力推动剧情。

反转应来自已经出现的证据、承诺、行动或人物选择。法术可以让被掩盖的事实显现，但不能临时变出一个从未铺垫的罪行。一次求助被拒绝不足以证明对方恶劣，要通过具体行为建立双重标准或不公。

情绪可走向“理解处境—看见代价—发现不公—尝试应对—形成反转—获得实际帮助”，但这只是检查因果的路径，不是必须逐段照搬的固定模板。

### 4.1 固定结构：开头—故事—结尾

本系列固定采用“师徒对话引入—故事展开—师徒对话收尾”的结构：小和尚问出疑惑，人物经历给出答案，济公简短点明。结构固定，具体问题、情节、台词和节奏按每集故事创作，不重复套用同一句问答。

**固定角色：** 小和尚俗家名许小安，济公平时叫他“小安”，每集出场。他替观众提问，看完事情后说出自己的理解；名字在全系列统一，不随集更换。

**开头：小和尚提问，济公引出故事。**

- 小和尚先开口，问一个与本集人情矛盾有关的问题，替观众说出疑惑。优先说出一个很多观众也有的看法或误解（如“人太好说话就活该吃亏”），而不只是问眼前某件具体的事；故事再用经历回应它。
- 开头与结尾放在同一个地点（如寺门台阶、小区门口石墩），和故事发生的地方分开，把故事夹在中间；首尾机位尽量一致。
- 济公简短回应，引导他去看、去听。
- 留下疑问，进入故事；开头不提前讲透道理或揭示反转答案。
- 对话要像两人遇到眼前的事自然聊起来，避免生硬地“今天给大家讲个故事”。

**故事：让人物经历事情，让观众自己产生情绪。**

- 交代人物想做什么、为什么为难，让委屈有具体原因。
- 通过行动、对话和前后对照，逐步显出人情矛盾。
- 济公亲自介入，用机智和法术推动转折，帮助当事人。
- 反转有铺垫，笑点来自人物行为，最后让受助者真正得到帮助。

**结尾：事情有结果，回到济公和小和尚，回应开头。**

- 先让观众看到当事人的处境发生了什么变化。
- 小和尚看过事情后，先用自己的话说出理解（如“师父，我明白了……”），回应并修正开头的看法；必要时可追问一句。
- 济公用一句简短、通俗、有余味的话点到为止，不重复复述故事，不另起一段长篇说教。
- 最后可以留一个温暖或带喜感的小动作，视故事情绪决定，不强行添加笑点。

开头提出的问题必须由本集人物经历回应，结尾的点明必须来自已经发生的事。师徒对话不能代替实际解决问题，也不能为等到结尾才点明而拖延济公必要的帮助。不为三个部分规定统一秒数。

## 5. 我们采用的拍摄方法

| 要素 | 固定要求 | 每集按需决定 |
| --- | --- | --- |
| 场景与美术 | 人物生活条件、道具用途、服装磨损彼此一致；环境可被人物使用 | 古今、贫富、色彩、地点 |
| 构图 | 统一9:16竖屏；交代谁在什么地方、谁掌握主动权；对话中人物视线和方向可理解 | 具体景别、人物位置与空间层次 |
| 镜头 | 全景交代关系，中景呈现行动，近景观察变化；特写承担重要信息 | 镜头数量、运动与长度 |
| 情绪 | 关键转折后看见当事人的反应；从克制到变化有过程 | 停顿长短、爆发程度 |
| 对照 | 用相关的动作、空间或物件呈现关系变化 | 是否使用相似机位、同一物件 |
| 法术 | 明确作用对象、发生过程与结果，结果能改变接下来的行动 | 表现方式、强度、次数 |
| 喜剧 | 笑点有可见起因和后果，优先来自掩饰、贪心、装腔和自相矛盾 | 是否语言笑点、动作笑点或两者配合 |
| 字幕 | 对白易读；说明文字只补画面难以表达的必要信息，避开脸与关键道具 | 字体大小、强调色、具体位置 |
| 声音 | 角色声音稳定、对白清楚；情绪来自表演，音乐只做支持 | 音色、方言、环境声、配乐；需样片试听后锁定 |
| 节奏 | 每段推进信息、行动、关系或情绪；转折需要观众看懂 | 总时长、切镜速度、停顿 |

全系列正式采用9:16竖屏。竞品的横向宽画面仅作为叙事与质感参考；分镜、人物站位、场景图和视频生成提示词均从源头按竖屏设计，不依赖横屏裁切。

竖屏执行要求：

- 对话以中近景、单人反应和适合空间的双人构图为主；需要时用过肩镜头交代交流对象，保留一致的视线方向。全景用于交代空间和完整动作，不规定景别比例。
- 多人同场优先利用前后景深与错位站位，避免所有人横向排开。每个镜头明确主要关注的人或动作。
- 委屈、犹豫和反转的关键时刻，让脸、手和相关道具在手机画面上可辨；不要为了放大脸而裁掉决定情绪含义的动作。
- 法术的施放者、作用对象与变化结果须在同镜头或连续镜头中交代清楚；先建立空间关系，再切局部变化和人物反应。
- 字幕避开脸、手与关键道具，右侧和底部为播放界面留出余量；发布前用实际预览检查遮挡，不预设未经验证的固定安全区数值。

避免为“电影感”而不断推拉摇移。人物的犹豫、选择和关系变化才是换镜头的理由。AI生成时检查脸、服装、手中物件、门的位置、人物视线和动作前后衔接；关键道具不允许在转场中自行出现或消失。

## 6. 表演、语言和喜剧

语言口语化，人物说话要完成目的：求助、推辞、遮掩、试探、讨价还价、维护尊严。避免所有人轮流讲金句。古代可以通俗，现代可以直接；都要符合人物的身份和关系。

用具体行为表现情绪：想开口又停住、笑容收起、把钱重新收好、端着碗等别人说完。不要仅写“十分委屈”“情绪爆发”而没有可演动作。

反派或占便宜的人可以讲礼貌、找理由、顾面子。不要靠从头到尾吼叫证明其恶劣。受助者也有脾气和判断，不必完美无缺。

济公有机趣，有分寸；温柔落在受助者身上，讽刺落在欺负人的行为上。不给苦难本身配取笑式音效，不拿弱者的贫穷、疾病或外貌当笑料。笑点之后仍需顾及人物的情绪，不立即把刚形成的心疼消解掉。

## 7. 时长、受众与商业目标

不为凑时长写戏，也不为压到固定秒数砍掉必要因果。先确定完整故事，再删掉重复信息。竞品约3分53秒只能证明这一条采用了这个长度，不能证明同长度一定有效。

首条作品重视理解门槛、矛盾清晰和回报兑现；不保证首条一定获得流量，也不把首次表现当成账号最终结论。不同故事按实际冲突决定更重情绪积累还是推进速度。

变现机会应与观众对角色的信任一致。不能为了展示产品让济公偏离角色，不能用商品代替原本应当成立的救助因果。

### 7.1 变现路线（2026-11-22确定）

账号从零开始，没有现成粉丝和商家资源。采用单元剧路线：每集完整解决一件事，先积累关注与信任，广告位在故事线阶段就设计进剧情。不走付费连续短剧（需每集停在悬念上，与本规范的完整单元结构冲突）。

| 阶段 | 目标 | 做法 |
| --- | --- | --- |
| 一、起号（当前） | 让人看完愿意关注、记住“这个济公” | 小和尚开头的疑问即钩子；济公外形、口头习惯和固定道具（破蒲扇、酒葫芦）每集一致；结尾一句点明短而好记；片中不硬喊关注。广告位先用无品牌的普通道具 |
| 二、有一定粉丝后 | 开始收入 | 把预留广告位换成品牌植入或定制集；与剧情相关的集可挂实用商品 |
| 三、长期 | 角色价值 | 济公固定道具做周边；避开“开光”等宗教功效类商品 |

广告位规则：

- 广告位是故事里本来就需要的生活服务或物件（如搬家车、纸箱、维修工具），由剧情需要决定，不为植入加戏。
- 广告位永远不能替济公解决问题，也不能成为受助者得救的原因。
- 阶段一用无标识道具；后期接到合作时，只重新生成相关镜头即可换成品牌，不改剧情因果。故事线中须标明广告位所在段落、类型（服务类／物品类）和出现次数。

平台的开通门槛与分成规则常有调整，具体数字以届时官方规则为准，本规范不固定。

## 8. 当前押金故事的应用约定

暂用标题：《房东扣押金，济公让出租屋变回入住前》。这是待继续打磨的故事线，不等于已经确认的成片剧本。

姑娘自行修补房屋，是过去体谅与付出的证据；搬家车等待，是她急着妥协的现实原因。济公让房屋回到真实的入住状态，揭示责任，法术规则提前说明。房东再要求先修复后退款时，姑娘坚持先结清押金。结尾应清楚呈现她收到钱、能够离开。济公帮她搬最后一箱东西可以成为温暖落点。

不默认济公最后替房东免费修好一切，以免抵消房东行为的后果。若要恢复房屋，必须有合理承担与结算，不让受助者再次为他人的占便宜付出。

广告位：楼下等待的搬家车与搬家师傅（服务类，同时是姑娘急于妥协的现实原因）；装行李的纸箱与济公帮搬的最后一箱（物品类）。阶段一均无品牌标识。故事线见 `docs/故事线/01_房东扣押金.md`。

## 9. 交付前检查

- 是否先选话题、再定故事、最后写剧本？
- 开头是否由小和尚先提出贴近本集矛盾的疑问，济公简短引出故事，而未提前讲透答案？
- 片名是否说明具体事情，成片是否兑现？
- 主角想要什么、为什么忍、付出多少，是否能够从行为看懂？
- 不公平来自具体事实，还是仅靠作者要求观众讨厌某个人？
- 反转有无先前依据？人物选择是否符合其处境？
- 济公是否发挥了作用？法术是否改变了冲突？
- 笑点是否明确，受助者是否得到尊重？
- 是否删掉了情节已经表达过的重复说理？
- 受助者最后具体得到了什么？有没有留下新的无故损失？
- 结尾是否先呈现实际结果，再回到师徒对话回应开头？济公是否简短点明，避免复述和说教？
- 镜头、字幕、声音是否共同服务同一时刻的情绪？
- 是否从源头按9:16构图，关键表情、动作、法术结果与字幕在竖屏预览中清楚可见？
- 时长是否由有效内容决定？
- 广告位是否来自剧情本身的需要？是否标明段落与类型？有没有替济公解决问题？换成品牌时是否无需改动因果？
