对应剧本：`docs/剧本/01_房东扣押金.md`（10场版）
声音设定：`docs/声音/声音设定_济公与小安.md`

## 使用方法

1. 「朗读文本」一栏可以直接复制进剪映的文本框，**一行生成一段音频**。标点已经按朗读效果调整过，和剧本字幕可能略有不同；字幕请以剧本为准。
2. 「语速」一栏指生成后在「变速」里设置的倍数，1.0 表示不改。如果你的剪映版本在朗读面板里就能调语速，也可以在那里调。
3. 「处理」一栏写的是停顿、音量和特殊效果。
4. 同一个角色全集只用一个音色。第一次挑好以后，把音色名称填到下面的角色音色表里。

## 最后检查

- [ ] 每个角色全集只用了一个音色。
- [ ] 三个男声（济公、周叔、老刘）、两个女声（林小满、小陈）能一听分清。
- [ ] 济公的笑声用的是真人录音或固定的音效，没有让 AI 念“哈哈”。
- [ ] 手机外放听一遍，每句都听得清，背景音乐没有盖过对白。
- [ ] 第53句前后没有音乐或音效抢声音。
