## 它做得好的地方（可吸收）

1. **开头直接抛命题。** 第一秒就是小和尚的疑问，而且是反常识的说法：“越善良最后越无情”。观众马上想知道为什么。
2. **对普通人的共鸣强。** “帮别人被当成应该”几乎人人遇到过。四次快速的帮忙让观众先认同张三，再心疼他。
3. **金句集中、方便截图。** “失望攒够了”“收手叫清醒”很适合评论区引用和转发。
4. **角色形象统一。** 济公的尖顶破帽、灰僧衣、佛珠、破蒲扇、葫芦，以及小和尚的长相，全片保持一致。
5. **门和门缝用得好。** 求助被拒时隔着门缝说话，关系一眼就能看懂。
6. **镜头节奏稳。** 平均约 3.5 秒一个镜头，以对话为主，不炫技。

## 它的不足（我们的机会）

1. **济公什么都没做。** 他全程旁观、解说，没有出手，也没用法术。妻子因为没钱看病死了，济公就在村里。这和我们规范里“遇见困难会介入”的济公完全不同。
2. **最重的事只用一句字幕交代。** 妻子去世只有一句橙字、一只空碗，没有人物反应，情绪落空。
3. **说理太多。** 师徒插话三次，结尾再说 60 秒，约占全片四分之一。同一个道理反复讲。
4. **结局没有解决问题。** 张三失去了妻子，最后只是“学会拒绝”，观众得到的是感慨，不是痛快。
5. **说明性字幕多。** 橙字负责交代大部分因果，靠字幕讲故事，不靠画面。
6. **横屏。** 在竖屏平台上，画面被缩在中间。

## 对我们第1集剧本的启发

| 编号 | 建议 | 理由 |
| --- | --- | --- |
| A | 开头小安的问题更尖一点，带出反常识的味道 | 竞品第一秒就抓人。我们现在的“图什么”偏温和 |
| B | 开头加两三个很快的镜头，交代小满三年里自己修房子（深夜补墙、换龙头） | 竞品靠“先看她付出”建立共鸣。我们目前只用语音和购物记录口头交代，属于“说”而不是“演” |
| C | 结尾金句保持一句，但要足够好记、能被截图 | 竞品靠金句传播，但它说得太多。我们只留一句，但要有分量 |
| D | 关键事实（到账、真相）一律用画面和人物反应交代，不用说明字幕 | 避开竞品“大事一句橙字”的问题 |
| E | **扇子的问题** | 竞品和传统济公都用破蒲扇。我们剧本写的是“扇子一合”，那得是折扇。改成折扇会和经典形象不同；保留蒲扇的话，法术规则要改成“正扇一下变回去，反扇一下回来” |
